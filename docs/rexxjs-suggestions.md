# Suggestions for RexxJS

RexxJS and RexxAE track each other's language and functions as far as that
is possible ([rexxjs-tracking.md](rexxjs-tracking.md)). This page collects
what RexxJS could take from RexxAE, and behaviour in RexxJS that looks like a
bug against classic (ANSI) Rexx, each with a test program and where in
RexxJS's source the change would go. Nothing here has been pushed to RexxJS;
each item waits for a decision on how it lands.

(Filled in as the tracking work finds items.)
